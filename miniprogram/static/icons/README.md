# TabBar 图标文件说明

需要在 `static/icons/` 目录下放置以下图标文件：

## 必需图标（共6个）

### 首页图标
- `home.png` - 首页未选中图标（灰色，建议 #999999）
- `home-active.png` - 首页选中图标（主题色，#4A90D9）

### 分类图标
- `category.png` - 分类未选中图标（灰色）
- `category-active.png` - 分类选中图标（主题色）

### 我的图标
- `user.png` - 我的未选中图标（灰色）
- `user-active.png` - 我的选中图标（主题色）

## 图标规格要求

| 属性 | 建议值 |
|------|--------|
| 尺寸 | 81px × 81px (推荐) 或 60px × 60px |
| 格式 | PNG（支持透明背景） |
| 大小 | 单个文件不超过 40KB |
| 风格 | 线性/面性统一，建议使用线性风格 |

## 图标设计建议

- 使用简洁的线性图标风格
- 未选中状态使用 #999999 灰色
- 选中状态使用 #4A90D9 主题蓝色
- 图标内容清晰，线条简洁
- 避免过于复杂的细节

## 获取图标的途径

1. **阿里巴巴矢量图标库 (iconfont.cn)** - 免费，资源丰富
2. **IconPark** - 字节跳动开源图标库
3. **Tabler Icons** - 开源图标集
4. 自行设计 - 使用 Figma、Sketch 等工具

## 示例图标内容

- **home**: 首页/房屋图标
- **category**: 四宫格/分类图标
- **user**: 人物/个人中心图标
